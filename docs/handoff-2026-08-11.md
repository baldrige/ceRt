  both links, `conf_2017-09-25.html` included. Verified live.

Note on the patcher: the dry run predicted 280 and the real run touched 303. The
dry run asks "does this page have the right count", `patch_feed_links()` asks
"would the file change" — and for the 23 already-correct leaves it moves the
links to just before `</head>`. Same content, different position. It converges
after one run (a re-run reports `unchanged`), but the two predicates are not the
same and were described as if they were.
